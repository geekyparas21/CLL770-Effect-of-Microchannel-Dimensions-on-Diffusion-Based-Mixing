# Effect of Microchannel Dimensions on Diffusion-Based Mixing

**Course:** CLL770 – IIT Delhi
**Software:** COMSOL Multiphysics 6.3

## Project Overview

This project investigates diffusion-based mixing in a two-dimensional T-shaped microchannel using COMSOL Multiphysics.

The study examines the influence of outlet-channel dimensions on mixing performance by independently varying:

- Outlet-channel width: 50–150 µm
- Outlet-channel length: 1–5 mm

## Methodology

- Laminar Flow simulation
- Transport of Diluted Species
- Stationary study
- Parametric sweeps
- Concentration variance and mixing-index evaluation
- Mesh-sensitivity analysis

## Repository Structure

- `COMSOL Model/` – COMSOL simulation model
- `Report/` – Final report and figures
- `Results/` – Numerical results and exported tables

## Key Findings

- Increasing outlet-channel width decreases the mixing index under the simulated conditions.
- Increasing outlet-channel length improves the mixing index.
- The observed trends remain consistent across the two mesh resolutions examined.
